# Project: Life Dashboard

## Overview
A Nezuko-themed To-Do Life Dashboard built with HTML, CSS, and Vanilla JavaScript.
No frameworks, no backend, no build tools. Open `index.html` directly in a browser.

## Stack
- HTML5 (`index.html`)
- CSS3 (`css/style.css`) — single file only
- Vanilla JS (`js/app.js`) — single file only
- Browser LocalStorage API for persistence

## Key Rules
- Only 1 file allowed in `css/` and `js/`
- No npm, no frameworks, no bundlers
- All features must degrade gracefully without a server
