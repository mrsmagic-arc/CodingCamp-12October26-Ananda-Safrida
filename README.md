# 🌸 Life Dashboard — To-Do List Dashboard

> A beautiful Nezuko-themed personal dashboard built with pure HTML, CSS, and Vanilla JavaScript.  
> No frameworks. No backend. Everything runs in the browser.

🔗 **Live Demo:** https://mrsmagic-arc.github.io/CodingCamp-12October26-Ananda-Safrida/

---

## ✨ Features

| Feature | Description |
|---|---|
| 🕐 **Clock & Date** | Live real-time clock (12h AM/PM) with full date |
| 👋 **Smart Greeting** | Time-aware greeting (Morning / Afternoon / Evening / Night) with custom name |
| 🎯 **Focus Timer** | Pomodoro timer with Short & Long Break modes, custom durations, session counter |
| ✅ **To-Do List** | Add, edit, complete, delete tasks — with All / Active / Done filters |
| 🔗 **Quick Links** | Bookmark grid with favicons — add and remove your favorite sites |
| 🌙 **Light / Dark Mode** | Toggle with one click, persists across sessions |
| ⚙️ **Settings** | Set your custom name shown in the greeting |
| 💾 **Local Storage** | All data (tasks, links, theme, name, timer settings) saved in the browser |
